# Inkscape 

![inkscape](https://drive.google.com/thumbnail?id=1_s89_IhFZsjSG8vUn59WhdeedukCCnyy&sz=w800)

Inkscape is a free graphic design software that is used to create and edit vector graphics. It can be used to make logos, posters, illustrations, icons, and other desings.

Inkscape provides tools for drawing shapes, editiong paths, adding text and applying colors. Additionally, it ca also be used for creating desings that can be used for printing and lasar or vector cutting. 

Most importantly, since it uses vector graphics the desings can be made bigger or smaller without making it blurry. 

![vector-vs-raster(pixel)](https://drive.google.com/thumbnail?id=1lzkSlxdWCEU0nntFxcKOfIN4Ui6RrrhF&sz=w800)
### Raster Images
Examples (File Formats): JPEG (.jpg), PNG (.png), GIF (.gif), TIFF (.tif), and Photoshop (.psd)

### Vector Images
Examples (File Formats): Scalable Vector Graphics (.svg), Adobe Illustrator (.ai), Encapsulated PostScript (.eps), and PDF (when created with vector data).
